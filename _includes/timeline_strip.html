{% comment %} Horizontal strip of portrait thumbnails — built for Google Maps Timeline day-maps, but works for any set of phone-shaped photos. Parameters: - items: semicolon-separated list of "file.webp|Caption" pairs, or "file.webp|Caption|Alt text" triples. Each file resolves under /images/. The caption shows under its thumbnail; the optional third field is the img alt. Omit it and the alt falls back to "Timeline day-map — " plus the caption, so pass real alt text whenever the strip holds something other than day-maps. No field may contain a pipe or semicolon - those are the delimiters, and a stray one silently splits an entry; fragments with no pipe are skipped rather than rendered as a broken thumbnail. Quotes and angle brackets are safe, since every field is escaped on output. - caption: optional italic line under the whole strip. - gallery: GLightbox gallery name, default "timeline". All strips sharing a name form one swipeable set in DOM order, so the default lets you page through every day of the trip chronologically from any thumbnail. Give an unrelated set its own name so it doesn't join that sweep. Portrait phone screenshots (442x733) share the row width, so 2-4 per strip reads best. Each thumbnail links to the full-size image since labels are unreadable at strip size. Wraps on narrow screens. The style block is emitted only once per page.
