{% comment %} Horizontal strip of day-map thumbnails (Google Maps Timeline screenshots). Parameters: - items: semicolon-separated list of "file.webp|Caption" pairs. Each file resolves under /images/. The caption shows under its thumbnail. - caption: optional italic line under the whole strip. - gallery: GLightbox gallery name, default "timeline". All strips sharing a name form one swipeable set in DOM order, so the default lets you page through every day of the trip chronologically from any thumbnail. Portrait phone screenshots (442x733) share the row width, so 2-4 per strip reads best. Each thumbnail links to the full-size image since labels are unreadable at strip size. Wraps on narrow screens. The style block is emitted only once per page.
