{%- comment -%} One Den comic strip: an anchored "## #N — Title" heading, a glightbox wrapped full-res image (all strips share data-gallery="the-den" so they page through together), and the collapsed "receipts" details block that links to the real transcript gist behind the strip. Params: num - strip number, e.g. "3" title - strip title, e.g. "The Secret Almost Shipped" date - display date, e.g. "August 27, 2026" img - image path, e.g. "/images/den/den-003.webp" alt - full alt text for the image receipts_url - direct link to the gist with the real transcript. Optional: omit it and the receipts block is left off entirely rather than rendered as a dead link. note - optional extra markdown rendered between the image and the receipts (e.g. a link to an alternate style) The heading text, the image's data-description, and the figcaption are all built from num + title + date so that string isn't repeated three times per strip.
