{% comment %} Belief-equation builder (interactive). The reader picks or types an external behavior, picks the link (cause-effect "makes me feel" or complex equivalence "means") and picks or types an internal state; the belief sentence assembles live with each part color-coded the same way as the explorer (external behavior = evidence blue, link = amber, internal state = conclusion rust). "Run the patterns on it" drops the sentence into the LLM prompt (_includes/sleight-of-mouth-prompt.html) when that is on the page. Seeds: equation_seeds in _data/sleight_of_mouth.yml. Without JavaScript it falls back to the seed sentences. Self-contained, no libraries, no network. Used by: _d/2016-3-12-sleight-of-mouth.md {% endcomment %}
